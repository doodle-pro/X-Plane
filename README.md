## 🎮 About X-Plane69

### Inspiration
I wanted to build an immersive, 3D web-based flying game that pushes the limits of what's possible in the browser, inspired by classic arcade flight simulators but with a modern, minimalist twist.

### What it does
**X-Plane69** is a fast-paced 3D flying game where you pilot an aircraft over the ocean. The objective is to fly to the mainland by collecting blue energy pills to sustain your flight while carefully dodging red obstacles that will bring your journey to a sudden halt.

### How we built it
The game is built entirely from scratch during the hackathon using modern web technologies, focusing on performance and 3D graphics directly in the browser without requiring any plugins. 

I utilized **Three.js** to handle the 3D scene, rendering, collision detection, and WebGL context. Smooth animations and transitions are powered by **TweenMax (GSAP)**.

### Challenges we ran into
One of the main challenges was handling 3D collision detection in a web environment and ensuring smooth performance and high frame rates across different devices without sacrificing the low-poly visual quality. Fine-tuning the flight controls to feel responsive and natural also required significant testing within the short 12-hour window.

### Accomplishments that we're proud of
I am extremely proud of creating a visually engaging, responsive 3D web game that runs seamlessly in any modern browser. Hitting the deadline with a fully working, playable demo that matches the Frontier Cascadia requirements was a massive win!

### What we learned
I deepened my knowledge of WebGL concepts, 3D coordinate mathematics in Three.js, optimizing 3D geometries for the web, and setting up an efficient asset bundling pipeline under a strict time limit.

### What's next for X-Plane69
In the future, I plan on adding more dynamic weather environments, multiplayer support, diverse power-ups, and global leaderboards to make the flight experience even more competitive and thrilling.
